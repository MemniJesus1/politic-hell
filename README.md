# ⚜ POLITICHELL — единый репозиторий проекта

Всё в одном месте: исходники движков, документы, облачный комплект для запуска сервера рядом с тобой (минимальный пинг).

## Структура

| Папка | Что это |
|---|---|
| `engine/` | **PoliticHellEngine** — 3D-меню Стиль 1.1 (Обложка/Арсенал/Ящики/Штаб, колесо эпох) |
| `hud/` | **PoliticHellHUD** — HUD денег/статусов + обновлятор, под мигшей DeluxeMenus (Фаза 0) |
| `docs/` | МАСТЕР-ПЛАН MK-1, аддон «Инструменты и мораль», облачный гайд, правила агента |
| `cloud/` | Скрипты для виртуальной машины (Ubuntu): установка, автозапуск, обновление jar-ов |
| `scripts/` | Локальные удобства: запушить на GitHub, упаковать сервер в архив, создать SSH-ключ |
| `.github/workflows/` | Автосборка jar-ов при каждом пуше (GitHub Actions) |

## 🚀 Публикация на GitHub (3 шага, один раз)

1. В браузере: **https://github.com/new** → имя репозитория (например `politic-hell`) → Create repository (пустой, без README).
2. Двойной клик: `scripts\ЗАПУШИТЬ_НА_GITHUB.bat` → вставь ссылку `https://github.com/ТВОЙ_НИК/politic-hell.git` → Enter.
3. Откроется окно браузера для входа в GitHub → залогинься, разреши. Всё — проект в облаке. Проверь вкладку `Actions`: сборка обоих jar-ов пойдёт сама.

## ⚙️ Автосборка (CI)

- **Любой пуш** → GitHub Actions собирает `PoliticHellEngine-*.jar` + `PoliticHellHUD.jar` → артефакт во вкладке Actions.
- **Пуш с тегом** (`git tag v1.17.0 && git push --tags`) → создаётся **Release** с.jar-ами — оттуда их качает облако.

## ☁️ Сервер в облаке (Google Cloud, рядом с тобой)

Полная пошаговая инструкция: **[docs/ОБЛАКО_ГАЙД.md](docs/ОБЛАКО_ГАЙД.md)** — от создания VM до подключения игроков. Коротко:

```
GitHub = склад проекта + автосборка (код не запуск 24/7 тут нельзя)
Google Cloud VM (Варшава/Франкфурт) = там живёт сам сервер 24/7, минимальный пинг
Google Drive = только склад файлов/бэкапов (сервер на Диске работать не может — там нет процессора)
```

## 🔁 Как обновляется облачный сервер

```bash
# на VM (одной строкой, после того как ты запушил новый код и Create Release по тегу):
sudo bash /opt/politichell/deploy_jars.sh <ТВОЙ_НИК>/politic-hell
```

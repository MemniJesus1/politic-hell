# ☁️ POLITICHELL В ОБЛАКЕ — гайд от нуля до игры (Google Cloud)

> Сначала честно: **Google Drive и GitHub не могут быть сервером.**
> - **Google Drive** = просто склад файлов (там нет процессора).
> - **GitHub** = склад проекта + автосборка jar'ов (сервер там можно хостить только отрывками по 6 часов, это не для 24/7).
> - **Google Cloud** (та же учётка Google!) **= настоящая виртуальная машина**, на которой сервер живёт 24/7.
>
> Схема, которую мы строим: **GitHub хранит проект и собирает jar'ы → Google Cloud VM запускает сервер → ты и друзья играют с минимальным пингом.**

## Выбор места (пинг)

Точно ориентир — Украина ₴ / запад СНГ:

| Регион Google | Город | Ожидаемый пинг |
|---|---|---|
| **europe-central2** ✅ | **Варшава** | ~10–35 мс (лучшая ставка) |
| europe-west3 | Франкфурт | ~25–45 мс (запасной) |
| europe-west4 | Амстердам | ~30–50 мс |

Правило: создал VM → в PowerShell `ping IP_АДРЕС` → если больше 60 мс, лучше пересоздать VM в другом регионе (это 5 минут).

## Стоимость (честно)

| Виртуалка | CPU/RAM | Цена 24/7 |
|---|---|---|
| **e2-standard-2** ✅ | 2 vCPU / 8 ГБ | ~30–35 $/мес |
| e2-medium (бюджет) | 2 vCPU / 4 ГБ | ~15 $/мес (нужен своп — уже в скрипте) |

**Пробный период Google: 300 $ на 90 дней** → первые 2–4 месяца бесплатно. Диск 25 ГБ ≈ 2 $/мес.

## ШАГ 0. Создать проект (5 минут)

1. Открой **https://console.cloud.google.com** и войди своим Google-аккаунтом.
2. Сверху рядом с логотипом: выпадашка проектов → **«Создать проект»** → имя `politic-hell` → Создать.
3. Если предложат **включить пробный период** (300 $) — включи (нужна карта с международной оплатой).

## ШАГ 1. Создать серверную машину (VM)

1. Меню ☰ → **Compute Engine → Виртуальные машины → Создать**.
2. Настройки:
   - **Регион:** `europe-central2 (Варшава)`, зона любая;
   - **Тип:** E2 → `e2-standard-2` (2 vCPU, 8 ГБ);
   - **Диск:** Образ `Ubuntu 24.04 LTS` (minimal тоже ок), объём 25 ГБ, тип «Стандартный постоянный»;
   - **Межсетевой экран:** отметил «Разрешить трафик HTTP» — НЕ нужно, оставь только SSH.
3. **Создать**. Через минуту машина появится — запиши её **Внешний IP**.

## ШАГ 2. Ключ и доступ по SSH (на своём ПК)

1. Двойной клик: `scripts\СОЗДАТЬ_КЛЮЧ_SSH.ps1` — он напечатает **публичный ключ** (строка `ssh-ed25519 AAAA... politichell`).
2. В консоли GCP: ☰ → **Compute Engine → Метаданные → вкладка «SSH-ключи» → Изменить → Добавить элемент** → вставь эту строку целиком. Сохрани.

## ШАГ 3. Упаковать сервер и залить его в облако

1. Двойной клик: `scripts\УПАКОВАТЬ_СЕРВЕР_В_ZIP.ps1`
   → сделает `D:\...\_work\pack.tar.gz` (~3.5–4 ГБ: server.jar + плагины + миры + конфиги; логи/бэкапы — мимо).
   Хочешь начать в облаке с ЧИСТОГО мира (быстрее залить) — запусти с флагом: `.\УПАКОВАТЬ_СЕРВЕР_В_ZIP.ps1 -БезМиров`.
2. Залить на VM (в PowerShell):
   ```powershell
   scp -i "$env:USERPROFILE\.ssh\politichell_gcp" "D:\Programms\Minecraft SERVER ALL\_work\pack.tar.gz" politichell@ВНЕШНИЙ_IP:/tmp/pack.tar.gz
   ```
   4 ГБ на домашнем канале ≈ 30–60 минут. Поставь и иди пей чай.
3. Скопируй управляющие скрипты на VM (короткий вариант — через Consоль веб-SSH кнопкой «↥ Upload file» загрузить по одному; надёжный — scp):
   ```powershell
   scp -i "$env:USERPROFILE\.ssh\politichell_gcp" "D:\Programms\Minecraft SERVER ALL\POLITICHELL_REPO\cloud\*.sh" politichell@ВНЕШНИЙ_IP:/tmp/
   ```

## ШАГ 4. Установка (2 минуты)

1. В консоли GCP напротив VM нажми кнопку **«SSH»** — откроется терминал в браузере.
2. Выполни:
   ```bash
   sudo bash /tmp/setup_server.sh
   ```
   Скрипт: Java 21 → своп → файрвол → автозапуск → старт сервера.
3. Жди «Done» — смотри логи: `journalctl -u politichell -f`

## ШАГ 5. Заходи в игру!

В Майнкрафте: **IP_ВНЕШНИЙ:25565** (порт указывать не надо, он по умолчанию).

> 🔒 **Статический IP** (чтобы адрес не менялся после перезапуска): ☰ → Сеть VPC → IP-адреса → зарезервируй за VM. ~2 $/мес, при остановке VM — 0.
>
> ⚠️ **Безопасность:** у нас `online-mode=true` (только лицензии). Если друзья с пиратками — ставь `online-mode=false` **и одновременно `white-list=true`** (`/whitelist add ник`), иначе кто угодно зайдёт под чужим ником. В `server.properties` смени пароль RCON с `CHANGE_ME_STRONG_PASSWORD`.

## 🔁 Дальнейшие обновления (жизнь после запуска)

1. Ты меняешь код/конфиг → `git push` → GitHub Actions собирает jar'ы (вкладка Actions — артефакты).
2. Публикуешь версию: `git tag v1.17.0` + `git push origin v1.17.0` → автоматически создастся **Release** с jar'ами.
3. На VM одна команда:
   ```bash
   sudo bash /opt/politichell/deploy_jars.sh ТВОЙ_НИК/politic-hell
   ```
   (приватный repo — сначала положи токен как в шапке deploy_jars.sh).

**Конфиги сервера** (не jar, а yml/toml) — меняются через pack-архив: заново `УПАКОВАТЬ_СЕРВЕР_В_ZIP.ps1` → scp → `sudo bash setup_server.sh` (он аккуратно распакует поверх).

## 💰 Экономия (когда играете не каждый день)

- **Остановить VM** (выпадающее меню рядом с VM → Stop) = процессорные деньги ОСТАНАВЛИВАЮТСЯ, платишь только ~2-3 копейки за диск.
- Включить обратно = 1 минута («Запустить»), сервер сам стартует (systemd).
- Leaf сам «усыпляет» пустой сервер — меньше утилизации CPU.

## 🆘 Если Google Cloud не пойдёт (карту не примут — бывает в некоторых странах)

Подходит ЛЮБОЙ арендный VDS с Ubuntu 24.04 — весь наш комплект совместим без единой правки
(`setup_server.sh` + `deploy_jars.sh}). Дешёвые с оплатой из СНГ: aeza.net, vdsina.com, hostvds.com.
Принцип тот же: дешман 2 vCPU / 4–8 ГБ RAM, регион — ближайший дата-центр.


# PoliticHell Engine 1.16.0 — Фаза 0 (демо-модуль)

Готовый Maven-проект: движок экранных 3D-меню **Стиль 1.1** для PoliticHell
(сервер Leaf 1.21.11, Paper API 1.21.11-R0.1-SNAPSHOT, Java 21).

## Что внутри

- Экранный движок `Style1ScreenHub`: 5 вкладок — ОБЛОЖКА / АРСЕНАЛ 3D /
  ЭКИПИРОВКА / ЯЩИКИ / ШТАБ. Виртуальный курсор по мыши, hover-подсветка,
  3D-модель с разбором узлов, манекен (Mannequin, 1.21.9+), зум древа через колесо.
- Кейсы: анти-спам 6 сек, pity-гарантия «Эпика» на 40-м открытии,
  roll_id в консоль, выдача только после доигранной анимации.
- `TownyTerritoryBridge`: чанк → держава → цвет дипломатии (рефлексия,
  работает и без Towny как «дикая земля») + `PoliticalOverlayRenderer`
  для пиксельной заливки/границ на карте HOI4.
- Древо эпох 5×5 со списанием казны, сохраняется в `plugins/PoliticHellEngine/engine-data.yml`.

## Команды

| Команда | Алиасы | Что делает |
|---|---|---|
| /menu | /pda, /hub | Обложка (главное меню) |
| /arsenal | /pharsenal | 3D-арсенал |
| /equip | /phequip | Экипировка на манекене |
| /crates | /phcrates | Ящики снабжения |
| /strana | /phstrana, /tech | Штаб: древо эпох |
| /phengine reload reset | — | Админ: сброс pity/древа |
| /phcoins add set | — | Админ: тест-экономика |

Управление: мышь — курсор, ЛКМ — клик, колесо — скролл/зум,
Shift — закрыть, **Shift+F** — открыть/закрыть ПДА (обычный F не трогаем).

## Как собрать

1. `cd PoliticHellEngine`
2. Если Maven ещё не скачан: `INSTALL_MAVEN.bat` (однократно)
3. `СОБРАТЬ.bat` → `target/PoliticHellEngine-1.16.0.jar` → в `plugins/`
   (копия автоматически уходит в `_GoogleDrive\`)

## Фаза 0 «Демонтаж»: убрать старые сундучные меню

Когда зальёшь исходники PoliticHellHUD в Drive и я их получу — сделаю
замену точно по коду. До того момента запусти готовый скрипт (без зависимостей):

```powershell
powershell -ExecutionPolicy Bypass -File "D:\Programms\Minecraft SERVER ALL\_GoogleDrive\PATCH_PHASE0_HUD.ps1" -Root "F:\All Minecraft\PoliticHell"
```

Он ставит ранний return в installMenus/initMenus/setupMenus/registerMenus
(с бэкапами *.bak_phase0; повторный запуск безопасен). Дальше пересобери HUD.

⚠ Если HUD держит те же команды /menu — наш движок загружается раньше
(Engine < HUD по алфавиту) и занимает /menu сам; на случай конфликта
есть алиасы /pda, /hub, /pharsenal...

## Тест-чеклист (2 минуты на сервере)

1. `/menu` — открылась Обложка, курсор ходит по мыши, ЛКМ по «В БОЙ» телепорт на спавн.
2. `/arsenal` — колесо перебирает оружие, разбор узлов светит золотым/синим.
3. `/equip` — манекен в костюме, клик по строке меняет комплект.
4. `/crates` — вскрой Полевой ящик: рулетка ~2 сек, приз с roll_id, повтор через 6 сек.
5. `/strana` — колесо зумит древо, ЛКМ исследует ячейку I_1 бесплатно.
6. Выйти из меню: Shift или урон по себе.
7. Рестарт сервера — «призраков» меню не осталось (auto-purge).
